# Beyond the Behaviour

An interactive decision-making resource for secondary teachers supporting students with an established ADHD diagnosis or identified support need.

Built for EDF1070. The site does not diagnose ADHD. It helps teachers practise:

**Notice → Interpret carefully → Respond concretely → Ask the student → Review impact**

## Run locally

```bash
npm install
npm run dev
```

## Build and deploy

The Vite `base` is `./`. Pushing to `main` builds the site and publishes it to GitHub Pages:

https://iwilleatyoubanana.github.io/beyond-the-behaviour/

```bash
npm run build
```

## AI use

The concept, scenarios, evidence choices and pedagogical decisions were designed from unit materials, current ADHD research and educational guidance. Generative AI assisted with visual assets and coding. Content, evidence claims, interactions and wording were reviewed and edited by the student author.
